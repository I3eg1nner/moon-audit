- 文件级 baseline 按出现次数消费：已有一次告警不会屏蔽后来新增的同指纹告警；同一份 baseline 可重复使用，行号移动保持身份，旧版无文件条目保留全局匹配。

- 扫描子命令统一检查配置和源码解析失败。生成 baseline 失败时保留原文件；pipeline 写出基础诊断报告后停止，不再打印成功或继续生成摘要、PoC、修复与 LLM 脚本。
- CFG 验证模式绕过调用者共享的函数缓存，重新生成验证诊断，也避免把不同验证模式的结果混用。
- CI 的 Unix 安装增加完整下载/安装的有限重试；各平台独立运行。拆开 Windows 的连续 native 命令，防止后一个成功命令掩盖前一个失败。
- Action 在目标文件系统内暂存并原子替换通过验证的报告；目录目标拒绝写入、符号链接替换不跟随，上传只使用本轮有效的 SARIF。
- 新增 `scripts/benchmark.py`：交错运行两个固定二进制，验证告警全部字段、重复次数、文件错误与扫描文件数，保存每个样本及中位数/最小值/最大值。
